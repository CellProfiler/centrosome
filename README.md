## Deprecation Notice

Although not yet archived, this repository is under minimal maintenance to remain compatible with the `4.2.x` branch of `cellProfiler`, which is itself receiving only bug fix updates.

For CellProfiler version 5+, `centrosome` has been made renamed `centriole`, and made a subpackage of the main [CellProfiler repo](https://github.com/CellProfiler/CellProfiler/tree/main/src/subpackages/centriole), where it is subject to heavy modification.

For the use of `centrosome` in `cp_measure`, refer to [this issue](https://github.com/afermg/cp_measure/issues/112).

# centrosome

`centrosome` is an open source image processing library. It is mostly used as a dependency of CellProfiler, however it can be used in isolation.
